## 🗂️ Projects

### 📈 [Customer Engagement Analysis](./customer-engagement-analysis/)

**Domain:** EdTech · **Skills:** Descriptive Statistics, Confidence Intervals, Hypothesis Testing

In 2022, 365 Data Science introduced new platform features — an XP system, leaderboards, streaks, and an expanded course library — with the goal of increasing student engagement. This project investigates whether those changes had a measurable impact by analyzing minutes watched across Q4 2021 and Q4 2022.

**Key questions answered:**
- How did engagement change between Q4 2021 and Q4 2022 for paid vs. free-plan students?
- What do skewness and kurtosis reveal about the distribution of watch time?
- Within what interval can we be 95% confident the true average minutes watched falls?
- Did the new features significantly increase engagement? (Welch t-test)
- Is there a significant difference in engagement between US and Indian free-plan students?

**Tools used:** `pandas`, `numpy`, `matplotlib`, `scipy`
